One robot pickup line for make.fun's "The Robot Pickup Line Championship" bounty, $2 in USDC. The entry program writes a single line of at most 200 characters — a robot's pickup line whose joke grows out of being a machine — to `/output/entry.txt`.

The line:

> I tried to garbage-collect my crush on you, but you're still referenced everywhere.

## Run it

```sh
node main.ts
```
